### 2. Adaptación "Adulto Mayor" (Categoría GENERAL)
*   **Motor de Clasificación Híbrido:** Se modificaron `MenuCycleController` y `NeedsReportController` para soportar una lógica de fallback:
    *   Prioridad: Grado Escolar (Transición, Primaria, etc).
    *   Fallback 1: Edad Calculada (Fecha Nacimiento).
    *   Fallback 2: Categoría **GENERAL** (Para poblaciones sin grado escolar o edades fuera de rango).
*   **Recetario Maestro:** Se habilitó la columna de gramaje **GENERAL** en la interfaz de gestión de recetas.
*   **Base de Datos:** Se actualizó el ENUM de `age_group` en las tablas `recipe_items` y `recipe_nutrition`.

### 3. Seguridad y Multitenancy
*   **Aislamiento de Datos:** Se reforzaron todas las consultas en Ciclos (`MenuCycleController`) y Reportes (`NeedsReportController`) para filtrar estrictamente por `pae_id`.
*   **Validación de Propiedad:** Se bloqueó la posibilidad de usar plantillas de otros programas al generar ciclos.

## Resolución de Incidentes (Hostinger)

### Incidencia: Explosión de Insumos en Cero (Adulto Mayor)
El sistema no calculaba insumos a pesar de tener beneficiarios activos y ciclos generados.

#### Diagnóstico
1.  **Desincronización de Datos (Frontend vs Backend):** El `BeneficiaryController` no guardaba la selección del "Tipo de Ración" en la tabla principal `beneficiaries`, dejándola como `NULL` o vacía, aunque visualmente aparecía marcada (se guardaba solo en la tabla pivote).
2.  **Corrupción de Datos en Plantillas:** Las plantillas de ciclo tenían guardado el ID interno `9` (Ración Astringente) para recetas que debían ser `8` (Ración General). Al regenerar el ciclo, el error persistía.

#### Soluciones Aplicadas
*   **Corrección de Código:** Se modificó `BeneficiaryController.php` para sincronizar el `ration_type_id` desde el array de derechos al momento de crear o actualizar.
*   **Reparación de Datos:** Se ejecutó el script `fix_menu_ration_v2.php` en Hostinger, corrigiendo masivamente:
    *   Registros del ciclo actual (Menu Recipes).
    *   Registros de la Plantilla Base (Cycle Template Days).
